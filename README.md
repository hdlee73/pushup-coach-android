# PushUp Coach

카메라 속 신체 관절을 기기 내에서 인식해 정확한 푸쉬업만 기록하는 안드로이드 앱입니다. 촬영 영상이나 이미지는 저장하거나 전송하지 않습니다.

## 주요 기능

- MediaPipe Pose Landmarker의 33개 신체 포인트를 이용한 실시간 자세 인식
- 팔꿈치 각도(내려감 95° 이하, 올라옴 155° 이상)와 몸 정렬을 함께 검사하는 반복 판정
- 잘못된 허리/골반 정렬, 관절 가림, 동작 범위 부족에 대한 실시간 안내
- 일일 목표 설정, 오늘 진행률, 누적 기록 및 최근 7일 기록
- 목표 달성 연속 일수 계산(오늘이 진행 중이면 어제까지의 기록 유지)
- 숫자 음성 안내 및 목표 달성 알림
- Room 로컬 데이터베이스 저장, 오프라인 동작

## 실행 방법

1. Android Studio에서 이 폴더를 엽니다.
2. Gradle 동기화가 끝나면 Android 8.0(API 26) 이상의 실제 기기를 연결합니다.
3. `app` 실행 구성을 실행하고 카메라 권한을 허용합니다.
4. 휴대폰을 몸의 옆쪽 약 2~3m 거리에 두고, 머리부터 발목까지 화면에 들어오게 합니다.

자세 인식 모델은 `app/src/main/assets/pose_landmarker_lite.task`에 포함되어 있습니다. 카메라 분석은 후면 카메라와 최신 프레임 우선 방식으로 처리합니다.

## 판정 방식

한쪽 어깨·팔꿈치·손목·골반·발목 중 가시성이 더 높은 쪽을 선택합니다. 몸 각도가 150°보다 작으면 자세를 먼저 교정하도록 안내하고 카운트하지 않습니다. 올바른 몸 정렬에서 팔꿈치가 95° 이하로 내려갔다가 155° 이상 펴지면 1회가 기록됩니다. 임계점 사이에 여유 구간과 450ms 중복 방지 시간을 둬 카메라 흔들림에 의한 중복 카운트를 줄였습니다.

## 검증

핵심 반복 판정과 연속 달성 계산에는 JVM 단위 테스트가 포함되어 있습니다.

```text
gradlew.bat test
```

기기와 촬영 각도에 따라 관절 각도 오차가 달라질 수 있습니다. 실제 운동 환경에서 여러 체형·조명·카메라 높이로 테스트한 뒤 `PushUpCounter`의 임계값을 조정하는 것을 권장합니다.
